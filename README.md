# Irfan Afandi - IT & IoT Single-Page Portfolio

Portofolio profesional berbasis web statis/single-page yang dirancang khusus untuk menampilkan keahlian di bidang **Information Technology & Internet of Things (IoT)**.

## 🚀 Fitur Utama
- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Tailwind CSS dengan Rich Dark Mode (`#030712`) dan aksen Emerald Green & Cyan
- **Ikon**: Lucide React
- **Struktur Halaman**:
  1. **Hero Section**: Headline tebal, *status availability badge*, deskripsi, dan tombol CTA.
  2. **About Section**: Narasi integrasi hardware fisik dengan sistem software/cloud.
  3. **Skills & Tech Stack**: Grid terstruktur menggunakan ikon Lucide (Embedded C/C++, MQTT, Python/JS/Next.js, Linux & Cloud).
  4. **Projects Showcase**: Kartu showcase proyek IoT (Smart Agriculture, Industrial Telemetry Gateway, LoRa Station, Smart Energy).
  5. **Contact & Social**: Form kontak responsif dan tautan langsung ke GitHub, LinkedIn, dan Email.

## 📦 Menjalankan Proyek

1. Masuk ke direktori proyek:
   ```bash
   cd D:\Aku\portfolio
   ```

2. Pasang dependensi:
   ```bash
   npm install
   ```

3. Jalankan server development:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:3000`.

4. Untuk membuat build produksi:
   ```bash
   npm run build
   ```
